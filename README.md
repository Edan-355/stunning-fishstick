# What is this?

This program is a March Madness Bracket Simulator written in Python. It simulates a small NCAA-style basketball tournament using 8 teams. The program assigns seeds to each team and then plays through the Quarterfinals, Final Four, and Championship to determine a national champion.

Instead of using a live sports API, the program uses backup data that mimics an API response. Game outcomes are decided using random scores, with higher-seeded teams receiving a slight advantage. This makes the tournament more realistic while still allowing upsets to happen.

When the program runs, it prints the tournament seeds, simulates each round, displays the results of every game, and announces the final champion.

# Why?

This program was created to practice working with APIs, randomness, and simulations in Python. It demonstrates how real-world events like March Madness can be modeled using code, even when a real API is unavailable.

The project is useful for AP Computer Science Principles because it applies key computer science concepts such as functions, conditionals, loops, lists, dictionaries, randomness, and error handling in a meaningful and engaging way.
